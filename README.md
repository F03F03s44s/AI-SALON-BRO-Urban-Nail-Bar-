Three matching OS packages, one shared data hub:

- `Urban Nail Bar (macOS High Sierra)` — primary
- `Urban Nail Bar (macOS Big Sur)`
- `Urban Nail Bar (Windows 11)`

## One-click start

| OS | File |
|----|------|
| Windows 11 | `START-SALON.bat` or `START-SALON.vbs` |
| macOS High Sierra / Big Sur | `START-SALON.command` |

Every start: **backup → sync data → mirror UI across all 3 → start server**.

## Shared data

- Live: `_shared-salon-data/data-store.json`
- Backups: `_shared-salon-data/backups/`
- Sync engine: `_sync/MIRROR-ALL-THREE.js`

Manual sync only: `_sync/MIRROR-ALL-THREE.bat` (Windows) or `_sync/MIRROR-ALL-THREE.command` (Mac).

See `HOW-TO-START.txt` for details.
